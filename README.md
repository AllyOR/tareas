# To do doo

Lista de tareas del día con una columna de hábitos saludables, tips, motivación e ideas de proyectos.

Es un solo archivo (`index.html`), sin servidor: las tareas se guardan en el navegador de cada dispositivo.

Funciona sin conexión: abre la página una vez con internet y queda guardada (service worker). Se puede instalar en la pantalla de inicio del teléfono.
La letra es la del sistema, sin descargas externas.
